## Функции

| Функция | Что делает |
| --- | --- |
| `findMax(numbers)` | максимум в массиве через цикл `for` |
| `filterAbove(numbers, limit)` | фильтрация: значения больше границы (долгожители, > 8 ч) |
| `getSum(numbers)` | сумма элементов |
| `getAverage(numbers)` | среднее, пустой массив даёт 0 вместо `NaN` |
| `countLowBattery(numbers, names, limit)` | цикл `while`: количество, доля и названия устройств с автономностью ≤ 4 ч |
| `askName()` | `prompt` с проверкой отмены и пустой строки |
| `round1()`, `formatNumber()` | округление до десятых и запятая вместо точки |
| `main()` | собирает расчёты и выводит результат |

Вся логика лежит в функциях, в глобальной области только данные, границы `LONG_LIFE`, `LOW_LIFE` и запуск `main()` по событию `DOMContentLoaded`.

## Отладка

- `console.log` после каждого расчёта, чтобы видеть промежуточные значения, а не только итог.
- Точка останова (breakpoint) на строке с вызовом `countLowBattery` во вкладке Sources: в панели Scope видно, как меняются `count` и `i` на каждом шаге цикла.
- Проверка крайних случаев: отмена `prompt` (возвращается `null`) и пустая строка — оба случая дают имя «Гость»; пустой массив в `getAverage` даёт 0, а не `NaN`.
- `'use strict'` в начале файла, чтобы опечатка в имени переменной выдавала ошибку, а не создавала новую глобальную переменную.
